# 🧮 Calculadora de Matemáticas Discretas

Aplicación web para resolver ejercicios de **Matemáticas Discretas**: conjuntos, relaciones, combinatoria, aritmética modular y grafos, con resultados y visualizaciones al instante.

## ✨ Módulos

| Módulo | Qué hace |
|---|---|
| **Conjuntos** | Unión, intersección y subconjuntos (A ⊆ B, B ⊆ A) |
| **Universo** | Operaciones de A, B y C sobre un conjunto universo, con diagrama de Venn |
| **Relaciones** | Relaciones A×A, A×B y B×B, y operaciones entre relaciones (R1 ∪ R2, R1 ∩ R2) |
| **Combinaciones y permutaciones** | Conteo a partir de los elementos y la cantidad |
| **Aritmética modular** | Congruencias y operaciones `mod` |
| **Grafos** | Dibujo interactivo, matriz de adyacencia y grado de cada vértice |

## 🚀 Cómo ejecutarlo

```bash
npm install
npm start
```
